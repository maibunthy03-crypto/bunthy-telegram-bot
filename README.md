# Maline Premium Language Bot

## Railway
1. Delete the old project files or create a new Railway service.
2. Upload all files from this ZIP.
3. Add Railway Variables:
   - BOT_TOKEN
   - OWNER_ID
4. Set Start Command to:
   npm start
5. Deploy.
6. Add the bot to your Telegram group and make it administrator.
7. Test `/ping`, then `/languages`.

Only one deployment may use the same BOT_TOKEN.
